SSPUR Playground Docs Reference
Press Run, or Ctrl+Enter (Cmd+Enter on a Mac).

This page runs SSPUR's checker and interpreter in your browser, compiled to WebAssembly. Your code stays on this page; a share link carries it in the part of the URL after #, which the server never sees.

Programs run in the interpreter, the same one sspur run --interp uses, so output and test results match the command line. Some things work differently here:

  • fs works on a file system in memory that starts empty, with / and /tmp, on every run. Symlinks aren't supported.
  • env is empty and args() is []. read_line sees no input.
  • time uses the browser's clock. sleep_ms moves the clock forward instead of waiting.
  • Recursion goes a few hundred calls deep rather than 20,000, because a browser gives the page a much smaller stack.
  • par tasks run one after another, which gives the same results unless a task waits on a channel that a later task fills.
  • proc, extern fn (C interop), named time zones, packages, services and native code aren't available. They report an error instead of running.

The token count is a rough estimate of about four characters per token, not the tokenizers the token benchmark uses.

To run programs on your machine, with native code, see Installation.
